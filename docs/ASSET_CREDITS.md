# Asset credits
The original gauge emblem and six generic body-style SVGs were authored in this repository. PNG install icons are rasterizations of the original mark. No manufacturer badges or third-party car photographs are bundled. These silhouettes are explicitly labeled generic, not exact model depictions. User photos stay in IndexedDB and take precedence over silhouettes. System fonts are retained as fallbacks. The interface is English-only; user text is not restricted.
User-supplied concept images were inspected in the conversation as visual references. Their original binaries were not available in the workspace; they have not been copied or misrepresented as bundled assets.

Phase 4 adds original AI-generated `alpine-road.png`, `crossover-studio.png`, `hatchback-studio.png` and `sedan-studio.png`, generated for this project. They contain no manufacturer logos and are explicitly illustrative body-style fallbacks, not licensed manufacturer photos or exact-model renders. The silver crossover serves Sedici/SX4-like proportions; hatchback and sedan variants prevent a universal crossover image. Coupe, van and motorcycle retain original SVG fallbacks. Owner photos take priority. The four original PNG assets total approximately 7.8 MiB and are cached for offline reuse; initial loading requires this additional download.

Phase 6 derives optimized WebP versions of the four original generated PNGs using standard resize/compression (quality 82 for scenery, 85 for vehicles). The original PNGs remain as provenance in source control. Only the 455,346-byte WebP set is loaded/cached and included in the runtime package. No new third-party imagery or manufacturer badges were added. The later 1000034610.jpg attachment was available locally and reviewed as a design reference; it is not a bundled runtime asset.

Version 1.1 replaces the original A symbol with a newly authored vector gauge and rasterized 192/512px app icons. Manrope Latin variable font is locally hosted from `@fontsource-variable/manrope` 5.3.0; copyright 2019 The Manrope Project Authors, SIL Open Font License 1.1. The full license ships at assets/fonts/OFL.txt and is included in the offline artifact. No external font requests are made at runtime.
